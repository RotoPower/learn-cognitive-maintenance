# plant-api (Cloudflare Worker)

Port of `plant/api.py` to Cloudflare's free tier: the deterministic simulator in
TypeScript (`src/sim.ts`, byte-compatible hashing with the Python sim), the clock
as a Durable Object (`src/clock.ts`), and tables in D1 (`migrations/0001_schema.sql`).

Routes, tokens and semantics are identical to the Python API, so `plantctl` and the
Colab notebook work unchanged with `PLANT_API_URL=https://<worker>.workers.dev`.

## Local

```bash
npm install
cp .dev.vars.example .dev.vars        # READ_TOKEN / ADMIN_TOKEN for wrangler dev
npm test                              # vitest in workerd (Miniflare D1 + DO)
npm run dev                           # http://127.0.0.1:8787
```

## Staging (one-time)

```bash
wrangler login
wrangler d1 create plant-staging      # paste database_id into wrangler.toml [env.staging]
npm run d1:migrate:staging
wrangler secret put READ_TOKEN --env staging
wrangler secret put ADMIN_TOKEN --env staging
npm run deploy:staging
```

Then `PLANT_API_URL=https://plant-api-staging.<account>.workers.dev uv run plantctl clock`.

## Design notes

- **Clock**: `sim_time = anchor_sim + (now - anchor_real) * speed`, persisted in the
  DO. Computed on read; no per-second alarm is needed for correctness. `speed=0` pauses.
- **Only state**: the DO (clock, seed, injected faults) and D1 (work orders, artefacts,
  ground-truth mirror). Readings are never stored by this Worker; the ingest Worker
  (D2.2) writes `readings` from `/tags/latest`.
- **Parity**: `test/fixtures/parity.json` is generated by
  `uv run python scripts/export_parity_fixture.py`; regenerate it whenever
  `plant/sim.py` or `plant/faults.yaml` changes, and mirror `faults.yaml` in
  `src/faults.ts`.
- **Environments**: `[env.staging]` and `[env.production]` have separate D1
  databases and DO namespaces. Production deploys only via git tag through CI (D2.6).
